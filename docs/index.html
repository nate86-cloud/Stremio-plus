Bypass Gatekeeper (unsigned)

App is unsigned — first launch shows a warning. Use one option per OS:

macOS — Stremio-Plus-1.0.0-x64.dmg → /Applications/Stremio Plus.app

xattr -cr "/Applications/Stremio Plus.app"
# or
sudo xattr -rd com.apple.quarantine "/Applications/Stremio Plus.app"

Or right-click → Open → Open, or System Settings → Privacy & Security → Open Anyway.

Linux — AppImage

chmod +x "Stremio-Plus-1.0.0.AppImage"
./"Stremio-Plus-1.0.0.AppImage"

Windows — exe

SmartScreen → More info → Run anyway. Portable zip: extract → run Stremio Plus.exe.

Also available in the app: open Info (ⓘ) in the sidebar → Landing Page → Full README.
